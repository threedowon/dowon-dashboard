# SEN0610 · ESP32-S3

전용 화면을 따로 실행하지 않습니다. `../../Start-Signal-Tester.cmd` → **센서 대시보드**를 사용하세요.

## 배선과 업로드

전원을 끄고 SEN0610 스위치를 IIC/I2C로 놓습니다.

- SEN0610 `+` → ESP32-S3 `3V3`
- SEN0610 `-` → `GND`
- SEN0610 `C/R` → `GPIO9` (SCL)
- SEN0610 `D/T` → `GPIO8` (SDA)

부팅 시 0x2A와 0x2B를 확인하고, 한 주소에서만 응답하면 해당 주소를 자동 선택합니다. PlatformIO에서 이 폴더를 열어 Build / Upload하고, CH343 USB COM 포트를 공통 테스터에서 선택합니다. 115200 / 8 / None / 1을 사용합니다. platformio.ini의 고정 COM20은 주석으로 바꿨으므로 실제 포트를 선택하세요.

## 주소 진단

이 폴더의 새 펌웨어를 보드에 업로드해야 적용됩니다. 테스터만 다시 실행하면 보드 프로그램은 바뀌지 않습니다. 기본 로그는 기존처럼 ready / detected / distance / near / error 5개만 출력합니다. 주소 자동 선택은 그대로 동작합니다.

주소 진단이 필요할 때만 해당 연결의 Serial → Raw data에서 **Text / LF**로 `i`를 전송하세요. **Latest received data → Text** 또는 Activity의 RX 기록에 아래 진단 항목이 함께 출력됩니다. `n` + LF를 보내면 다시 기본 로그로 돌아옵니다. 오류 상태에서도 이 명령을 사용할 수 있으며, 보드 재시작 시 기본 로그로 돌아옵니다.

- `firmware: "sen0610-address-v3"`: 선택형 주소 진단 및 초기 연결 재시도 펌웨어가 실행 중입니다.
- `i2c_2a: 1, i2c_2b: 0`: 0x2A에서 응답.
- `i2c_2a: 0, i2c_2b: 1`: 0x2B에서 응답.
- 둘 다 0: 두 주소 모두 응답 없음. 배선·전원·IIC 모드 등을 확인합니다. 이것만으로 고장 여부를 단정할 수 없습니다.
- 둘 다 1: 두 주소에서 응답, Error=7로 정지합니다. 다른 I2C 장치가 연결되어 있는지 확인하세요.
- `i2c_address_hex`: 시작할 때 선택한 주소(`0x2A` / `0x2B` / `none`). 숫자 필드 `i2c_address`는 각각 42 / 43 / 0입니다. 센서를 분리해도 선택했던 주소는 남으므로 현재 응답은 `i2c_2a`, `i2c_2b`로 확인합니다.
- `i2c_code_2a`, `i2c_code_2b`: Wire 통신 결과 원본 코드. 0이면 응답 성공이며, -1은 아직 검사 전입니다. 상세 오류 코드는 사용 중인 Arduino 코어에 따릅니다.

주소 응답은 그 주소에 장치가 있다는 뜻이며, SEN0610 모델 식별이나 정상 측정 완료를 보장하지 않습니다. Ready=1, Error=0도 함께 확인하세요. 초기 연결에서 Error=1(응답 없음) 또는 Error=7(두 주소 응답)이면 약 1초마다 재시도하며, 한 주소에서만 응답하고 연결에 성공하면 자동으로 설정·측정을 진행합니다. 모드/범위 설정 실패(Error=2~4)는 여전히 재시작이 필요합니다. 전원을 켠 채 배선이나 스위치를 바꾸지 마세요.

## 값과 범위

- 거리: cm, 유효 대상 없음/오류 시 -1
- Near: 30~60cm 범위의 유효 대상일 때 1
- Ready: 정상 측정일 때 1
- Error: 0 정상, 1 연결, 2 모드 전환, 3 범위 설정, 4 설정 확인, 5 측정 통신, 6 센서 동작 상태 오류, 7 두 후보 주소 모두 응답

측정 설정은 30~300cm이고 근접 판정은 30~60cm입니다. 2.5m 관람용으로 조정하려면 `NEAR_MIN_CM`, `NEAR_MAX_CM`을 바꾸고 다시 업로드한 뒤 화면의 모니터 이름도 맞추세요. 이 프리셋은 이전 근접 시험 범위를 그대로 가져온 것이며 관람용 거리 설정이 아닙니다.

센서 거리·속도 모드와 미세 움직임 감지를 사용합니다. 초기 연결 오류1/7은 자동 재시도합니다. 오류2~4는 배선·설정 수정 후 재시작하고, 오류5/6은 정상 측정 통신·상태가 복구되면 자동으로 재개합니다. Near>0.5가 1초 유지될 때 선택적으로 `person` 신호를 보냅니다. 정지 관람객·통행객·여러 사람은 실제 공간에서 확인하세요.
