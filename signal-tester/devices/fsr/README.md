# FSR 4채널 · ESP32-S3

전용 화면을 따로 실행하지 않습니다. `../../Start-Signal-Tester.cmd` → **센서 대시보드**를 사용하세요.

## 배선

```text
3V3 ─ FSR1 600mm ─┬─ GPIO1
                 └─ 10kΩ ─ GND
3V3 ─ FSR2 800mm ─┬─ GPIO2
                 └─ 10kΩ ─ GND
3V3 ─ FSR3 800mm ─┬─ GPIO4
                 └─ 10kΩ ─ GND
3V3 ─ FSR4 600mm ─┬─ GPIO5
                 └─ 10kΩ ─ GND
```

2단자 저항형 FSR 기준입니다. 신호선 네 개는 서로 연결하지 않습니다. **5V를 사용하지 마세요.** GPIO 번호는 헤더 순번이 아닙니다. 전원을 끄고 배선합니다. 저항은 센서마다 1개, 10kΩ은 시험 시작값입니다.

## 기준값 설정과 임계값

- 기본 펌웨어는 부팅 직후 자동 보정을 하지 않습니다. 원본 ADC값은 계속 표시되지만 Ready=0, Detected=0입니다.
- 상판·러그만 올리고 추가 하중을 제거합니다. FSR 연결 → Serial → Raw data에서 **Text / LF**, `c`를 Send data로 전송합니다. 약 2초 후 Ready=1을 확인합니다.
- FSR 원본값(raw1~raw4)과 기준 대비 증가량(delta1~delta4)을 같은 대시보드에서 확인합니다. 기본 켜짐 기준은 +60, 꺼짐 기준은 +30입니다. 각 센서값은 kg이 아닙니다.
- `t 1 80 40` + LF를 보내면 1번 센서의 켜짐/꺼짐 증가량을 80/40으로 변경합니다. 센서번호는 1~4, `0 ≤ 꺼짐 < 켜짐 ≤ 1023`입니다. 변경할 때는 자동 규칙을 정지하세요.
- 설정은 전원/리셋 시 초기화됩니다. 고정할 값은 `src/main.cpp`의 `onDelta`, `offDelta`를 수정합니다. 재연결 때 리셋될 수도 있으므로 Ready를 다시 확인하세요.

## 상태

| 값 | 뜻 |
| --- | --- |
| Ready=0 / Calibrating=0 / Error=0 | 기준값 미설정, `c` 전송 필요 |
| Calibrating=1 | 약 2초간 보정 중, 손대지 않기 |
| Error=1 | 보정값 900 이상: 사전 압력·회로 확인 |
| Error=2 | 보정 중 값 범위 30 초과: 움직임·노이즈 확인 |
| Error=3 | 위 두 오류 모두 |
| command_error=1 (JSON) | 명령 형식 오류, 다음 정상 명령에서 해제 |
| saturated_mask ≠ 0 (JSON) | ADC 상단 근처 채널. 비트1/2/4/8은 센서1/2/3/4 |

Ready는 보정 완료이지 단선 진단이 아닙니다. 상판 없이 센서별 반응부터 확인한 뒤 조립하세요. 기준값 설정 시 가해진 일정한 외부 하중은 상판 무게와 구별할 수 없습니다. 허용하중과 구조 검증 전에는 작은 하중으로만 시험하세요.

응용 데이터는 100ms마다 JSON 한 줄로 출력합니다. 보정 중/실패 시 Detected=0입니다. 보정 정상 상태에서는 4개 중 하나라도 임계값을 넘으면 Detected=1입니다. 공통 테스터는 이 값이 1초 유지될 때 선택적으로 `person` 신호를 전송합니다. 규칙은 처음에 정지되어 있습니다.
