Signal Tester v1.2.0 — 프로그램 안에서 업데이트

- 실행할 때 새 버전을 확인하고, 업데이트 버튼으로 내려받아 자동 교체·재실행합니다.
- SHA256과 파일 크기를 확인한 뒤 교체합니다. 다운로드 실패 시 기존 EXE를 유지하고 새 버전 시작 실패 시 이전 EXE로 복구합니다.
- 기존 포트·Signal·센서·규칙 설정과 대시보드 백업 계정 연결은 그대로 유지합니다.
- 재실행 후 통신 연결과 자동 규칙은 정지 상태입니다.

**이전 v1.1.0 사용자는 이번 EXE를 한 번 직접 다운로드하세요. 이후 버전부터 프로그램 안에서 업데이트할 수 있습니다.**

Python 설치·연결 코드 입력 없이 실행하는 Windows 10/11 64비트 전용 앱입니다. 창의 × 또는 프로그램 종료 버튼으로 통신도 종료됩니다. 측정값과 송수신 기록은 업로드하지 않습니다.
