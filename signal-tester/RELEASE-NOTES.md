Signal Tester v1.2.1 — 앱 안에서 읽는 센서 코드 가이드

- 왼쪽 아래 Guide → 센서 코드 작성 가이드에서 Arduino·ESP32 작성법을 바로 확인합니다.
- 숫자·JSON·ADC 전송 예제와 Signal Tester의 그래프·자동 규칙 설정을 함께 설명합니다.
- 목차 이동과 코드 복사를 지원합니다. FSR·SEN0610 배선 안내 및 전체 소스도 포함해 인터넷 없이 읽을 수 있습니다.
- 기존 포트·Signal·센서·규칙 설정과 대시보드 백업 계정 연결은 그대로 유지합니다.
- 재실행 후 통신 연결과 자동 규칙은 정지 상태입니다.

v1.2.0 사용자는 프로그램 상단의 **업데이트 확인 → v1.2.1 업데이트**로 설치할 수 있습니다. 이전 버전은 최신 EXE를 직접 다운로드하세요.

가이드의 코드는 Arduino IDE 또는 PlatformIO에서 보드에 업로드합니다. EXE 업데이트는 센서 보드의 펌웨어를 변경하지 않습니다.

Python 설치·연결 코드 입력 없이 실행하는 Windows 10/11 64비트 전용 앱입니다. 창의 × 또는 프로그램 종료 버튼으로 통신도 종료됩니다. 측정값과 송수신 기록은 업로드하지 않습니다.
