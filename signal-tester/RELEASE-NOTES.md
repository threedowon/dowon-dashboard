Windows 10/11 64비트용 Signal Tester 전용 앱입니다.

1. **SignalTester.exe**를 다운로드하고 더블클릭하세요. 콘솔이나 브라우저 주소창 없이 전용 창이 열립니다.
2. **설정 자동 백업 → 대시보드 계정 연결**에서 기존 GitHub 계정에 한 번 연결하세요. 이후 설정 변경은 PC별로 자동 백업됩니다.
3. 다른 PC의 EXE에서도 같은 계정에 연결한 뒤 **백업 목록 새로고침 → 불러오기**로 설정을 복원하세요.

Python 설치와 연결 코드 입력은 필요 없습니다. **프로그램 종료** 또는 창의 **×**는 Serial·UDP 연결과 자동 규칙까지 종료합니다.

기존 로컬 설정은 그대로 사용합니다. 오프라인 변경은 PC에 저장하고 연결이 돌아오면 재시도합니다. 복원 전 현재 설정을 복구 파일로 보관하고, 복원 후 연결과 자동 규칙은 정지 상태로 시작합니다. 다른 PC에서는 COM 번호와 IP를 확인하세요.

측정값과 송수신 기록은 업로드하지 않습니다. 전용 창은 Windows의 Edge WebView2 Runtime을 사용합니다.
